# LOKAVERKEFNI-NTV

React TypeScript lokaverkefni NTV fyrir veitingastað Litla Lemon

## Project Description

Litla Lemon er responsiv veitingastað vefsíða byggð með React og TypeScript.
Verkefnip notar React Touter Dom til að búa til margar síður ásamt reusable components eins og Header og Footer.

Vefsíða inniheldur:

- Forsíðu
- Matseðil
- Um okkur síðu
- Hafa samband síðu
- Light mode og Dark mod

## Technologies

- React
- TypeScript
- React Router DOM
- CSS

## How to run

- npm install
- npm run dev
